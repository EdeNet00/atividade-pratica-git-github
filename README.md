# Atividade Prática Git/GitHub

## Objetivo

Projeto acadêmico para praticar versionamento de software com Git,
sincronização com GitHub e utilização do Visual Studio Code.

## Tecnologias

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Visual Studio Code

## Funcionalidades

- Página inicial com exibição da data atual.
- Calculadora para somar dois números.
- Contador com opções para aumentar, diminuir e reiniciar.

## Estrutura do projeto

- `index.html`: página inicial.
- `calculadora.html`: página da calculadora.
- `contador.html`: página do contador.
- `css/estilo.css`: estilos das páginas.
- `js/inicio.js`: exibição da data.
- `js/calculadora.js`: cálculo da soma.
- `js/contador.js`: controle do contador.

## Como executar

Abra o arquivo `index.html` em um navegador.
Na página inicial, acesse a calculadora ou o contador.

## Versionamento

O Git registra as alterações por meio de commits.
O GitHub armazena o repositório remoto.

As operações de commit, push, pull e consulta ao histórico
são realizadas pelo Visual Studio Code.
